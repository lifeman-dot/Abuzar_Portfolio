ABUZAR AHMED PORTFOLIO — LIVE READY

This package has the supplied portfolio images connected to the existing design.

LOCAL / VS CODE
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.
4. The website should load with all portfolio images.

GITHUB PAGES
1. Create/open a GitHub repository.
2. Upload ALL files from this folder to the repository's main branch.
3. The included .github/workflows/static.yml deploys the site using GitHub Pages.
4. In GitHub: Settings > Pages, use GitHub Actions if GitHub asks you to select a source.
5. Push to main and wait for the Actions deployment to finish.

IMAGE MAPPING
The supplied WhatsApp-named images were mapped to the portfolio project names used by the original HTML.
The extra Abuzar Ahmed logo image is included as assets/images/abuzar-logo.jpeg and is used as the favicon.

IMPORTANT
The site is static HTML/CSS/JS, so no Node.js, npm, database, or backend is required for this version.
